# 旋转倒立摆控制系统

本工程使用高云 FPGA 完成摆杆角度采集、自动起摆、双环控制、旋臂目标管理和本地触屏交互。上位机通过串口配置参数并记录真实测量数据。

## 工程入口

- FPGA 工程：`Rotary_Inverted_Pendulum.gprj`。
- 综合顶层：`src/ads8688_uart_top.v`。
- 上位机入口：`启动上位机.bat`，对应 `tools/adc_gui.pyw`。
- 保存参数：`tools/tuned_profile.json`。
- 上电配置：`src/tft_profile.hex`，由 `tft_profile_boot.v` 装载。
- 架构和接口说明：`docs/架构说明.md`。

## 控制数据流

摆杆电位器经 ADS8688 转换后取高 12 位，经有效性管理与滤波进入摆杆内环。编码器提供真实旋臂位置和速度；位置外环输出摆杆目标倾角，内环根据角度误差产生驱动控制量。驱动量经过运行状态仲裁、死区补偿和总限幅后进入 TB6612 接口。

用户设定目标、内部控制目标、真实编码器位置分别保存。补偿和运动柔化仅修改内部参考，不替换测量值。往复模式围绕启动中心切换目标，关闭时请求回中心。

## 配置与依赖

本工程面向嘉立创逻辑派 G1，主控为 GW2A-LV18。FPGA 器件、引脚、电平设置和时钟约束沿用源工程。串行引脚复用选项保存在实现配置中，命令行入口同时设置该选项。上位机优先使用 Python 环境中的串口库；缺失时加载工程内的压缩依赖。压缩依赖保留供应方原始实现与许可证，自主源码的说明性注释使用中文。

保存参数和上电配置分别服务于上位机配置与板端初始化。调整保存参数不会自动改写上电初始化文件；生成工具位于 `tools/generate_screen_boot_profile.py`，不会自动连接硬件。
