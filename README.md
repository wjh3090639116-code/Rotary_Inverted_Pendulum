# 旋转倒立摆控制系统

基于嘉立创逻辑派 G1（GW2A-LV18）的旋转倒立摆控制系统。FPGA 完成角度采集、编码器反馈、自动起摆、串级双环控制、旋臂定位及触屏交互；Python 上位机提供参数配置、状态监测、曲线显示与数据记录。

## 系统组成

| 组成 | 功能 |
| --- | --- |
| 逻辑派 G1 / GW2A-LV18 | 控制计算、运行状态管理及外设时序 |
| 自制 PCB 扩展板 | 采集、驱动、显示和实体按键的接口连接 |
| ADS8688 与摆杆电位器 | 采集摆杆角度，使用 16 位转换结果的高 12 位 |
| 电机与正交编码器 | 驱动旋臂，反馈旋臂位置与速度 |
| TB6612 驱动模块 | 电机方向、PWM 和使能控制 |
| 触摸屏与实体按键 | 板端状态显示、目标设定和运行操作 |
| 串口上位机 | 参数设置、板端回显、实时曲线与原始数据记录 |

## 控制结构

旋臂位置外环采用 PD 控制，根据编码器位置误差与速度生成摆杆目标倾角；摆杆内环采用 PID 控制，根据目标倾角与摆杆测量值生成电机控制量。输出经过运行状态仲裁、死区补偿和 PWM 总限幅后送入驱动模块。

系统分别维护用户目标、内部控制目标和实测位置。用户目标表示期望到达的位置；内部目标由有界静差补偿和运动参考生成逻辑计算；实测位置来自编码器反馈。半圈、整圈运动使用分段推进的内部参考，接近终点时降低参考推进速度。

自动起摆采用两阶段交替脉冲，满足直立捕获条件后切换到双环控制。往复运动在中心两侧按设定间隔切换目标，关闭后返回中心。

## 主要配置

| 项目 | 配置 |
| --- | --- |
| FPGA 器件 | GW2A-LV18PG256C7/I6 |
| 系统时钟 | 50 MHz |
| 摆杆角度数据 | ADS8688 转换结果 `[15:4]` |
| 内环周期 | 1 ms |
| 外环周期 | 可配置，参数文件当前保存值为 25 ms |
| 编码器换算 | 参数文件当前保存值为 1040 计数/圈 |
| 电机 PWM | 20 kHz |
| 串口波特率 | 115200 bit/s |
| 屏幕分辨率 | 320 × 240 |

ADS8688 模块的 AIN1 对应程序通道号 0。引脚位置与接口电平见 [`src/ads8688_test.cst`](src/ads8688_test.cst)，时钟约束见 [`src/ads8688_test.sdc`](src/ads8688_test.sdc)。

## 使用方法

### FPGA 工程

使用 Gowin IDE 打开 `Rotary_Inverted_Pendulum.gprj`。综合顶层为 `src/ads8688_uart_top.v`，器件、引脚和时序配置由工程文件及约束文件指定。

命令行构建使用 `build.bat`，需要将 Gowin 工具加入系统 `PATH`。串行引脚复用选项保存在实现配置中，并由构建脚本设置。

### 串口上位机

安装带 Tkinter 的 Python 3，运行根目录的 `启动上位机.bat`。主程序为 `tools/adc_gui.pyw`。上位机优先使用 Python 环境中的 pyserial，缺少该依赖时加载 `dependencies/pyserial.zip`。

连接对应串口后，可设置控制参数、起摆参数、位置目标、往复摆幅与间隔，以及最终 PWM 上限。设置是否生效以 FPGA 回显为准。双击旋臂角度曲线可进入全屏，查看实测角度、用户目标和误差。

### 板端操作

触屏提供起摆、停机、位置步进、正反转一圈及往复操作。实体按键调整以下参数：

| 按键 | FPGA 引脚 | 功能 |
| --- | --- | --- |
| BT0 | K14 | 位置步进增加 10° |
| BT1 | K15 | 位置步进减少 10° |
| BT2 | K13 | 往复单边摆幅增加 10° |
| BT3 | K12 | 往复单边摆幅减少 10° |

## 参数文件

`tools/tuned_profile.json` 保存上位机使用的控制与运动参数；`src/tft_profile.hex` 保存板端上电参数，由 `tft_profile_boot.v` 装载。两份文件分别用于上位机配置和 FPGA 初始化，修改上位机参数文件不会自动更新板端上电参数。

上电参数生成工具为 `tools/generate_screen_boot_profile.py`。控制模块、定点格式和参数流转关系见 [系统架构说明](docs/架构说明.md)。
